# Code Detection Training Dataset

代码相似性检测训练数据集

## 目录结构

```
codelibrary/
├── go/          # Go语言代码样本 (900+ files)
├── php/         # PHP语言代码样本
├── ruby/        # Ruby语言代码样本
└── test*.py     # Python测试文件
```

## 数据集说明

本仓库包含用于代码相似性检测模型训练的各种编程语言代码样本。

### 数据统计

- **Go**: 900+ 个代码文件
- **PHP**: 10 个代码文件  
- **Ruby**: 10 个代码文件
- **Python**: 2 个代码文件

## 使用说明

这些代码样本可用于：

1. 训练代码相似性检测模型
2. 测试代码剽窃检测算法
3. 构建代码指纹数据库
4. 开发代码分析工具
